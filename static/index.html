Custom plots from discovered slots Choose any exact Object.Slot and plot its underlying trace values. Plot definitions are saved with your RDF default.

There is no Mean/Median/Min/Max aggregation for plots. Line plots show the selected traces through time; box plots use the underlying selected-trace values to show distributions by period; bar plots use the actual trace values at the latest available period in each selected year. Annual slots from flags.rdf remain a special case: line/bar plots show the yearly sum of the 0/1 flags. Plot title and subtitle are editable for publication.
